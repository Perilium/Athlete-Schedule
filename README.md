# Hybrid 5.2 Workout Coach

Mobile-first Progressive Web App for the Hybrid 5.2 workout plan.

## What it includes

- Monday, Tuesday, Thursday, and Friday guided workouts
- Wednesday, Saturday, and Sunday recovery notes
- Guided mode and Flow mode
- Superset handling
- Equipment-change screens
- Unilateral left/right rep recording
- Local workout history with progression hints
- Offline caching through a service worker
- Installable PWA manifest for Android Chrome
- Wake Lock, vibration, and sound notification support where available

## GitHub Pages

After the files are in the repository:

1. Open the repository on GitHub.
2. Go to Settings.
3. Open Pages.
4. Under Build and deployment, choose Deploy from a branch.
5. Select `main` and `/root`.
6. Save.

The app should then become available at:

https://biniperelman.github.io/Workout-schedule/

On Android Chrome, open that URL, then use the browser menu and choose Install app or Add to Home screen.
